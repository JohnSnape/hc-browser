HC Cursor Editor

Mouse cursors for HyperCard IIGS and the HC Browser, in the IIGS's own cursor format. Everything runs in this page; nothing is uploaded.

Cursor

Pick what each pixel should look like: a color (in 640 mode each value has an even-column and an odd-column color), invert (flips whatever is under it, like the I-beam) or see-through. The hot spot is the red cross.

Cursors in a HyperCard IIGS stack

Cursors are resources of type $8027 in a stack's resource fork. Get the fork with CiderPress II (cp2 extract --preserve=naps disk.po "Stack"), open the file ending in r, and put it back with cp2 add --from-naps, as with icons.
