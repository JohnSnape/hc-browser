Icons in a HyperCard IIGS stack

A stack keeps its icons in its resource fork. Get the fork out of a disk image with CiderPress II: cp2 extract --preserve=naps disk.po "Stack" gives Stack#550001 and Stack#550001r. Open the file ending in r. After saving, put the downloaded fork back beside the data file and run cp2 rm disk.po "Stack", then cp2 add --from-naps disk.po "Stack#550001" "Stack#550001r".
