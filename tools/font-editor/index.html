HC Font Editor

Bitmap fonts for HyperCard IIGS and the HC Browser, in the IIGS's own font format (QuickDraw II, file type $C8). Everything runs in this page; nothing is uploaded.

Character

Click or drag to set pixels (the first click decides on or off). Blue line: the pen (character origin). Green: the advance. Red: the baseline; the shaded band is ascent and descent.
