HC Pattern Editor

The 16 paint patterns of a HyperCard IIGS stack, in color. Everything runs in this page; nothing is uploaded.

Pattern

A pattern is 16 × 8 screen pixels with values 0–3, tiled across the screen. Each value shows its even-column and odd-column color from the stack's color set.

Tiled, as it fills a shape (2× size, true aspect)

Stack

Open a stack's data fork. CiderPress II's cp2 extract --preserve=naps disk.po "Stack" writes it as Stack#550001 (the file without the r). Patterns live in the stack's header block; HyperTalk's set pattern to 17–32 picks patterns 0–15.
